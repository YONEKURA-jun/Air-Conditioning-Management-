# AirCon Manager

Arduino クライアントと Windows ホスト間のシリアル通信による空調管理・監視システムです。

---

## 概要

ホストPCから対象クライアントを選択し、温湿度情報の取得や機器制御を行います。

また、Windows API を利用したシリアルポート監視機能により、Arduino の接続・切断をリアルタイムで検知できます。

---

## システム構成

### HOST

- C言語
- Windows API
- シリアル通信（9600bps）
- マルチスレッド構成
- デバイス監視機能

### CLIENT

- Arduino Uno R3
- DHT11 温湿度センサ
- 4桁7セグメントLED
- 74HC595 シフトレジスタ

---

## 実装済み機能

### HOST

- クライアント選択
- COMポート接続
- 温湿度取得コマンド送信
- 温度設定変更
- 電源ON/OFFコマンド送信
- 温湿度データ受信
- ログ保存
- ログ表示
- USBシリアルデバイス監視
- COMポート接続・切断通知

### CLIENT

- 温湿度測定
- コマンド受信
- 電源状態管理
- LED通知
- 7セグメントLED表示
- シリアル応答
- 設定温度管理
- 設定温度変更受信

---

## 通信コマンド

| 値 | 内容 |
|----|------|
| 0 | 温湿度取得 |
| 1 | 温度設定変更 |
| 2 | 電源ON/OFF |

### 温度変更シーケンス

1. HOST → CHANGE_TEMP送信
2. CLIENT → 現在設定温度返信
3. HOST → 新設定温度送信
4. CLIENT → 設定温度更新
