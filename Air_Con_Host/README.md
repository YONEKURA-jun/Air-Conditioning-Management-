Serial Client-Host Monitor



ArduinoクライアントとWindowsホスト間のシリアル通信による状態監視システムです。



概要



ホストPCから複数のクライアントを選択し、シリアル通信経由で状態取得や制御を行います。

通信設定情報をテキストファイルから取得し、Windows API CreateFileA() を利用してCOMポートへ接続しています。



開発中に Windows 改行コード(\\r\\n)由来の不具合を確認し、文字列解析時の区切り文字を ",\\r\\n" として対応しました。
