Serial Client-Host Monitor

Arduino クライアントと Windows ホスト間のシリアル通信による監視システムです。

概要

ホスト PC から対象クライアントを選択し、シリアル通信を用いてセンサーデータを取得・記録します。

主な機能

クライアント一覧表示

ログ閲覧
クライアント側
ホスト命令受信

電源状態管理
LEDによる状態表示
スイッチ入力監視

開発時に発生した問題
COMポート接続失敗

CreateFileA() が ERROR_INVALID_NAME(123) を返す問題を確認。

原因は設定ファイル読込時に Windows 改行コード \r\n のうち \r が残存していたことでした。

修正内容

strtok(address_data, ",\r\n");
